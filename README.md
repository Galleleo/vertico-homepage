# Vertico – Bremische Spezialtechnik

Marketing website for Vertico – Bremische Spezialtechnik, a company offering machine rental,
tree felling & hedge trimming, and rope-access climbing/height work from Hagen im Bremischen.
Built with Next.js (App Router).

## Development

```bash
npm run dev      # start the local dev server
npm run build    # create a production build
npm run lint     # run ESLint
npx vitest run   # run the test suite
```
